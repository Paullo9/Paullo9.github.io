mac4DSTEM

A free, native macOS application for interactive 4D-STEM analysis: virtual imaging, Bragg disk detection, strain and orientation mapping, phase reconstruction. Built with SwiftUI, MLX and Metal so the work runs on the GPU in a laptop instead of a cluster queue. GPL-3.0.
